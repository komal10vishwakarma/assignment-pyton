ASSIGNMENT 1: STUDENT_MANAGEMENT_SYSTEM
=======================================

-------
A coaching institute wants to manage student records using
Python Database Connectivity (PDBC).

TABLE STRUCTURE
===============

Table Name: student_pdbc

Column       Data Type
--------------------------------
sid          INT PRIMARY KEY
sname        VARCHAR(50)
course       VARCHAR(50)
fees         DECIMAL(10,2)
city         VARCHAR(30)

===========
