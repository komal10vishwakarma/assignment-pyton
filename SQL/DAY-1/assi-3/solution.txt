Q1. Create a database named shop_db and use the database.

Q2. Create a table named product with:
- product_id  INT, PRIMARY KEY, AUTO_INCREMENT
- product_name – VARCHAR(50)
- category – VARCHAR(50)
- brand – VARCHAR(50)
- price – INT
- quantity – INT
